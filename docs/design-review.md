# Дизайн-ревью EVGO (ветка `design-polish`)

Дата: 2026-08-30. Автор: дизайн-проход по мобильному приложению и вебу.
Цель — убрать «странные моменты», привести всё к единой айдентике и
поднять до уровня конкурентов на рынке Узбекистана.

---

## 1. С чем сравниваем (конкуренты)

На рынке Узбекистана EV-зарядки уже есть игроки, на которых стоит
ориентироваться по ощущению продукта:

| Продукт | Что делает хорошо (ориентир для нас) |
|---|---|
| **Gigawatt** (Гигаватт) | Крупнейшая сеть. Спокойный, «инфраструктурный» тон: карта — главное, минимум рекламного шума. |
| **Tok Bor** | Утилитарный, быстрый доступ к статусу станции и запуску зарядки. |
| **Megawatt** | Операторское приложение — акцент на надёжности и статусе коннекторов. |
| Мировые (Tesla, Electroverse, Zapmap, ABRP) | Карта-герой, статус через цвет пинов (зелёный/жёлтый/серый), никаких «MEGA SALE». |

> ⚠️ Точные UI конкурентов нужно перепроверить вживую (скриншоты/установка).
> Здесь — принципы категории, а не копирование конкретных экранов.

**Главный вывод по категории.** Человек открывает приложение для зарядки
в состоянии лёгкого стресса (мало заряда, нужно быстро найти рабочую
станцию). Поэтому тон — спокойный, надёжный, «карта решает». Кричащая
распродажная эстетика («MEGA SALE ⚡ −30%» красным) читается как реклама
маркетплейса и подрывает доверие. Это и была главная причина ощущения
«странно выглядит».

## 2. Что было не так (находки)

### 🔴 Критично — конфликт с брендом

1. **Красно-оранжевые промо-баннеры.** Карусель на главной использовала
   градиенты `#7C0000→#DC2626` (кроваво-красный) и `#92400E→#D97706`
   (оранжевый) с бейджами «MEGA SALE / FLASH SALE / HOT DEAL». Бренд —
   сине-фиолетовый (`#2563EB` / `#7C3AED`). Красный кричал и выбивался.
   На свёрнутой шторке из-за края выглядывала «пустая красная плашка» —
   именно её видно на скриншоте пользователя.

2. **Перегруженная карточка станции.** На одной карточке одновременно:
   оранжевый бейдж «ТОП СТАНЦИЯ», **красный** уголок «−%», зелёная цена,
   жёлтая плашка «Экономия», сине-фиолетовая кнопка «Маршрут». Пять
   конкурирующих акцентов — глазу не за что зацепиться, ощущение пестроты.

### 🟠 Заметно

3. **Карта в вебе — сырые OSM-тайлы.** Пёстрая светлая подложка
   `tile.openstreetmap.org` выглядела дёшево и спорила с цветными пинами.
   На реальном телефоне (референс) карта тёмная и спокойная — веб не
   совпадал с нативом.

4. **Таймер обратного отсчёта — красный** (`rgba(220,38,38)` + `#FCA5A5`).
   Ещё один источник лишнего красного на баннере.

### 🟢 Мелочи / проверено — не баг

5. **Кнопка «Получить код» бледная** — это состояние `disabled`
   (`opacity: 0.5`), пока номер не введён полностью. При валидном номере
   становится полноцветной. Это корректно, не баг.

6. **Логотип «iON»** на старом скриншоте с телефона — это старая сборка.
   В коде уже везде `EVGO`.

## 4. Рекомендации на потом (нужно решение владельца)

Это уже вкусовые/продуктовые решения — не стал делать без согласования:

- **Упростить карточку станции.** Свести к иерархии: имя → статус (цвет
  пина) → цена → расстояние. «ТОП СТАНЦИЯ» и «Экономия» — оставить что-то
  одно, остальное убрать в детальный экран. Сейчас карточка выигрывает по
  плотности информации, но проигрывает по спокойствию — у конкурентов
  карточки «тише».
- **Промо-карусель — нужна ли вообще на главном экране?** Для утилиты
  зарядки ротация скидок сверху — агрессивно. Вариант: один аккуратный
  featured-баннер вместо карусели из трёх.
- **Тёмная карта на нативе.** Сейчас нативная `react-native-maps` — без
  `customMapStyle`, т.е. дефолтная светлая. Если хотим как на референсе
  (тёмная) — добавить `customMapStyle` JSON. Это отдельная задача.
- **Единый набор акцентов.** Зафиксировать: синий = основное действие,
  фиолетовый = бренд/промо, зелёный = «свободно/выгода», жёлтый = рейтинг,
  серый = офлайн. Красный — только настоящие ошибки. Пройтись по всем
  экранам и вычистить отклонения.

## 5. Как проверить

Веб-версия приложения (react-native-web) поднимается локально:

```
cd artifacts/mobile
EXPO_PUBLIC_DOMAIN="localhost:8080" npx expo start --web --port 19010
```

Открыть `http://localhost:19010`. В вебе станции из API могут не грузиться
(нужен запущенный API на :8080) — тогда показываются статические баннеры,
на которых как раз видно новую брендовую окраску.

На реальном устройстве — через Expo Go, ветка `design-polish`.
