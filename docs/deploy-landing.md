# Публикация лендинга

Лендинг — статический сайт: ни Node, ни базы ему не нужно. Поэтому он живёт
отдельно от бэкенда, а Replit остаётся под API и админку, где он действительно
нужен.

---

## Vercel — рекомендуемый путь

Бесплатно, свой домен, публикация за минуту, автоматическое обновление при
каждом пуше в `main`.

### 1. Импортировать репозиторий

1. Зайти на [vercel.com](https://vercel.com), войти через GitHub
2. **Add New** → **Project** → выбрать репозиторий `Raazzyy/EVGO`
3. Если репозитория нет в списке — **Adjust GitHub App Permissions** и дать
   доступ к нему

### 2. Настройки проекта

Vercel прочитает `vercel.json` в корне и подставит команды сам. Проверить,
что получилось:

| Поле | Значение |
|---|---|
| Framework Preset | Other |
| Build Command | `pnpm --filter @workspace/landing run build` |
| Output Directory | `artifacts/landing/dist/public` |
| Install Command | `pnpm install --frozen-lockfile` |
| Root Directory | оставить пустым — сборка идёт из корня, там воркспейс |

**Root Directory менять не нужно.** Лендинг зависит от корневого
`pnpm-workspace.yaml`, и если указать `artifacts/landing`, установка
зависимостей сломается.

### 3. Переменная окружения

**Settings** → **Environment Variables**:

| Имя | Значение |
|---|---|
| `VITE_API_URL` | `https://<ваш-репл>.replit.dev` |

Без неё карта покрытия покажет «Карта временно недоступна»: лендинг будет
искать API на своём домене, а его там нет. Всё остальное на странице
работает и без переменной.

Адрес репла виден в его окне — это тот же домен, по которому открывается
приложение. Не забыть `https://` и **без** слеша на конце.

### 4. Deploy

Нажать **Deploy**. Через минуту появится адрес вида
`evgo-<что-то>.vercel.app`.

### 5. Свой домен

**Settings** → **Domains** → добавить `evgo.uz`. Vercel покажет, какие
DNS-записи прописать у регистратора домена. Сертификат выпускается
автоматически.

⚠️ Домен нужен до подачи в App Store: ссылки на политику конфиденциальности
в заявке должны открываться.

---

## Что проверить после публикации

- главная открывается, переключаются языки `O'z / Рус / EN`
- `/privacy` и `/terms` открываются напрямую по адресу, а не только по ссылке
  из подвала (за это отвечают `rewrites` в `vercel.json`)
- карта показывает реальное число станций — значит `VITE_API_URL` задан верно

---

## Если API не отвечает с Vercel

Сервер уже отдаёт `Access-Control-Allow-Origin: *` (`app.use(cors())` в
`artifacts/api-server/src/app.ts`), поэтому запросы с чужого домена проходят.

Когда появится боевой домен, стоит сузить это до конкретного адреса: сейчас
API доступен любому сайту. Отдельная задача, до запуска не критично.

---

## Альтернатива: Netlify

Работает так же. В настройках указать:

```
Build command:    pnpm --filter @workspace/landing run build
Publish directory: artifacts/landing/dist/public
```

Плюс файл `artifacts/landing/public/_redirects` с содержимым:

```
/*  /index.html  200
```

Он нужен, чтобы `/privacy` и `/terms` открывались напрямую — у Netlify нет
`rewrites` из `vercel.json`.

## Замечание про Replit

На Replit лендинг запускается, но Preview остаётся пустым. Причина не в
коде — production-сборка проверена локально и работает. Скорее всего, дело в
том, как Replit обслуживает новый артефакт: он появился в списке только
после перезапуска воркспейса.

Если нужно именно на Replit — запускать через кнопку артефакта **EVGO**, а не
командой из Shell: тогда платформа сама подставит `PORT` и `BASE_PATH` из
`.replit-artifact/artifact.toml` и опубликует порт.
