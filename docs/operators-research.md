# Операторы зарядных станций Узбекистана — что удалось выяснить

**Дата:** 29 августа 2026
**Повод:** вопрос директора «нашёл ли API местных фирм?»

---

## Короткий ответ

**Публичных API ни у одного местного оператора нет.** Проверено запросами к
типовым адресам — везде 404 или домен не отвечает:

| Проверено | Результат |
|---|---|
| `tokbor.uz/api/stations` | 404 |
| `api.tokbor.uz` | домен не существует |
| `k-watt.uz/api/stations` | 404 |
| `api.electro.cars/ocpi/versions` | 404 |

Это ожидаемо и не означает, что интеграция невозможна: доступ по OCPI
операторы выдают **по договору**, а не открытым эндпоинтом. Публичный OCPI без
авторизации — редкость даже в Европе.

**Что это значит:** задача 77 из списка (запросить доступ у операторов)
остаётся единственным способом получить живые статусы. Обойти её технически
нельзя.

## Кто на рынке

### Операторы станций

| Компания | Сайт | Что известно |
|---|---|---|
| **TOK BOR** | tokbor.uz | Крупнейшая сеть, **около 150 станций** по стране. Своё мобильное приложение, **более 18 000 зарегистрированных водителей**. Есть раздел для бизнеса (business.tokbor.uz) — там же, вероятно, обсуждается партнёрство |
| **Megawatt Energy** | megawatt-energy.uz | Продажа и установка оборудования; сеть станций |
| **K-Watt** | k-watt.uz | Оператор станций |
| **QUWATT** | quwattstations.uz | Оператор, есть своё приложение |
| **PRO-TOK** | — | Местный производитель зарядного оборудования |

### Платформа управления

**Electro.cars** — система управления зарядными станциями, работающая в
Узбекистане. Заявляет **более 200 станций** на своей платформе: удалённое
управление сессиями, мониторинг, тарифы, биллинг, приложение и карта для
водителей.

Это самая перспективная точка входа: **одна интеграция с платформой может дать
доступ сразу ко всем станциям, которые к ней подключены**, вместо
переговоров с каждым оператором по отдельности. Поддержку OCPI/OCPP они на
сайте не заявляют — нужно спрашивать напрямую.

## Чего директор, возможно, не знает: рынок уже занят

На рынке **уже есть агрегаторы**, делающие ровно то же, что мы:

| Приложение | Что заявляет |
|---|---|
| **iWatt** | «Объединяет все зарядные сети по всему Узбекистану». Есть в App Store и Google Play. Карта всех станций, удобства (кафе, магазины, туалеты), отзывы и рейтинги станций, пользователи могут добавлять свои станции |
| **Gigawatt** | Объединяет зарядные станции в единую сеть |
| **Quwatt** | Приложение оператора QUWATT |
| **Zaryadka** | Приложение для зарядки электромобилей |

Плюс у **TOK BOR своё приложение с 18 000 пользователей** — то есть крупнейший
оператор уже имеет прямой канал к водителям и меньше всех заинтересован
отдавать своих клиентов агрегатору.

**Это не значит, что делать не нужно.** Но позиционирование «первый агрегатор»
не сработает, а разговор с операторами придётся строить иначе: не «дайте нам
данные», а «что вы получите взамен».

## Наша база против реальности

| | Станций |
|---|---|
| **В нашей базе сейчас** | **53** |
| Только у TOK BOR | ~150 |
| Всего коммерческих в стране (оценка на 2026) | более 1000 |

Мы видим примерно **5 % рынка**. Источник данных — OpenChargeMap, открытая
база, которую наполняют энтузиасты.

Обещание «все зарядки Узбекистана» при 53 станциях из тысячи не выполняется, и
это заметит первый же пользователь, который поедет к станции, которой у нас
нет. Наполнение базы — не менее срочная задача, чем интеграция.

## Что предлагаю сделать

### Немедленно, без переговоров

1. **Спарсить сайты операторов.** У TOK BOR, K-Watt, QUWATT станции опубликованы
   на сайтах — их можно разобрать и залить в базу с пометкой «данные с сайта
   оператора, не подтверждены». Это законно (публичная информация) и поднимет
   покрытие с 53 хотя бы до пары сотен.
2. **Проверить, что отдают их мобильные приложения.** Приложение TOK BOR
   показывает занятость станций — значит, где-то есть эндпоинт, который её
   отдаёт. Это **не** повод его дёргать без разрешения: такой доступ ломается
   при первом же обновлении и портит отношения с оператором до начала
   переговоров. Но знание, что API технически существует, усиливает позицию на
   переговорах: просить придётся не «сделайте нам интеграцию», а «дайте доступ
   к тому, что у вас уже работает».

### Переговоры — по приоритету

1. **Electro.cars** — платформа, одна интеграция даёт много станций сразу.
   Начинать с них: им выгодны новые каналы для операторов-клиентов
2. **TOK BOR** — крупнейшая сеть, но и самая самодостаточная. Нужен ответ на
   вопрос «зачем нам это»: например, доля от новых пользователей, которых мы
   приводим
3. **K-Watt, QUWATT, Megawatt** — меньше сети, выше мотивация: у них нет
   аудитории уровня 18 000 водителей, и агрегатор им скорее полезен

### Что спрашивать у каждого

Список вопросов уже готов в `docs/audit-and-roadmap.md`, этап 5:
поддерживают ли OCPI и какую версию, есть ли любой другой API хотя бы на
чтение статусов, условия роуминга, тестовый контур.

## Вопрос директору

**В чём наше преимущество перед iWatt?** Пока честный ответ — маршруты с
остановками под запас хода конкретной машины и оплата с единого баланса.
Первое у нас уже работает, второе требует этапа 2 (кошелёк).

Если преимущество только в «тоже карта станций» — конкурировать не с чем.
Стоит определиться с этим до того, как вкладываться в переговоры с операторами.
