# EVGO — запуск на Replit и сводка для ревью

Документ для директоров и для настройки на Replit. Технический справочник по
командам и всем переменным — в [`replit.md`](../replit.md); здесь — **порядок
действий** и **что уже сделано / что осталось**.

---

## Часть A. Первый запуск на Replit (по шагам)

> Всё выполняется один раз. Секреты добавляются в **Replit → Tools → Secrets**
> (не в код и не в git).

1. **Импортировать репозиторий** `github.com/Raazzyy/EVGO` в Replit (ветка `main`).
2. **Установить зависимости:** `pnpm install`
3. **Создать базу:** в Replit подключить Postgres (Replit DB / Neon) — появится
   секрет `DATABASE_URL`. Проверить, что он виден в Secrets.
4. **Добавить обязательные секреты** (без них API не стартует):
   - `DATABASE_URL` — Postgres (создаётся автоматически на шаге 3)
   - `PORT` — порт API (Replit подставит свой)
   - `ADMIN_JWT_SECRET` — подпись админ-токенов. Сгенерировать:
     `openssl rand -hex 32`
   - `AUTH_JWT_SECRET` — подпись пользовательских токенов (**задать отдельным**
     значением, не переиспользовать админский): `openssl rand -hex 32`
5. **Добавить рабочие секреты** (нужны для функционала, но сервер стартует и без них):
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — мастер-вход в админку
   - `YANDEX_JS_API_KEY`, `YANDEX_GEOCODER_KEY` — карта/геокодер (веб)
   - `GOOGLE_MAPS_ANDROID_KEY`, `GOOGLE_MAPS_IOS_KEY`, `GOOGLE_DIRECTIONS_KEY` —
     карты и построение маршрута (мобилка)
   - `CREDENTIALS_ENCRYPTION_KEY` — 32 байта base64 (`openssl rand -base64 32`),
     нужен для хранения `operators.api_credentials`
   - `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` — web-push
   - `EV_API_KEY`, `OCM_API_KEY` — живой поиск авто / импорт станций
6. **Создать схему БД:** `pnpm --filter @workspace/db run push`
   — создаёт все таблицы **и индексы идемпотентности платежей** (они уже в схеме).
   Для прод-контроля можно вместо push применить SQL-миграции по порядку:
   `docs/sql/*.sql` (по возрастанию даты, последняя — `2026-09-01-payment-idempotency.sql`).
7. **Импортировать станции:** `pnpm --filter @workspace/api-server run import:osm`
   (или `import:ocm`) — заполнит карту реальными станциями по Узбекистану.
8. **Запустить сервисы:**
   - API: `pnpm --filter @workspace/api-server run dev`
   - Админка: `pnpm --filter @workspace/admin run dev`
   - Лендинг: `pnpm --filter @workspace/landing run dev`
   - Мобилка (Expo): `pnpm --filter @workspace/mobile run dev`
9. **Проверка:** зайти в админку (`ADMIN_EMAIL`/`ADMIN_PASSWORD`) → Дашборд
   покажет число станций; открыть мобилку → карта со станциями.

> ⚠️ **Демо-вход для сторов:** пока заданы `DEMO_PHONE` + `DEMO_CODE`, любой,
> кто знает эту пару, войдёт под демо-аккаунтом. Задавать **только** на время
> ревью в App Store / Google Play и убирать сразу после.

## Часть B. Платежи и SMS — go-live (внешние договоры)

Эти шаги требуют договоров и делаются, когда они будут:

- **Payme:** после договора добавить секреты `PAYME_MERCHANT_ID` и
  `PAYME_MERCHANT_KEYS` (можно несколько через запятую). До этого касса
  «не настроена» и `/wallet/topup` честно вернёт «оплата временно недоступна».
  Merchant-webhook уже реализован (`/api/webhooks/payme`), проходит обе фазы
  песочницы `test.paycom.uz` после ввода реальных ключей. Тест-режим:
  `PAYME_TEST_MODE=true`.
- **SMS (Eskiz):** `ESKIZ_EMAIL`, `ESKIZ_PASSWORD` (секретный ключ из кабинета),
  `ESKIZ_FROM` (согласованное имя отправителя), `ESKIZ_CALLBACK_URL`. До этого
  OTP работает через `DEMO_PHONE`/`DEMO_CODE`.
- Домен `evgo.uz`, аккаунты Apple/Google Developer, доступ операторов (OCPI) —
  тоже внешние, вне кода.

## Часть C. Что уже сделано и проверено (для директоров)

**Готово и в проде/репозитории:**
- Мобильное приложение (карта, список, фильтры, маршрут с остановками под запас
  хода, избранное, сессии, тёмная тема, i18n) — Expo/React Native.
- Кошелёк: баланс, история, пополнение через Payme, холды под сессию, автосписание.
- Админ-панель: дашборд, финансы, станции, операторы, жалобы, сессии,
  пользователи, промо, баннеры, авто, поддержка — полностью на русском.
- Лендинг задеплоен (Vercel), с SEO: canonical, Open Graph, JSON-LD, sitemap,
  robots.
- ~473 реальных станции по Узбекистану импортированы.

**Аудит (проведён внутренне, готово к вашей проверке):**
- **Безопасность денег/токенов** — денежное ядро использует строковую блокировку
  `FOR UPDATE`, идемпотентность зачислений по платёжной транзакции, ротацию
  refresh-токенов, timing-safe авторизацию кассы Payme, fail-closed без ключей.
  Дополнительно добавлены **уникальные индексы БД**, делающие двойное зачисление
  физически невозможным (миграция `2026-09-01-payment-idempotency.sql`).
- **Мобилка (перф/вёрстка)** — список станций виртуализирован и мемоизирован;
  убраны отладочные логи; построение маршрута теперь переживает моргания сети
  (типизированные ошибки + авто-ретрай).
- Инструменты аудита (`.claude/skills/`): `security-review`, `code-review`, `seo`
  — можно прогонять самостоятельно по мере роста кода.

**Осталось (внешнее, не код):** договоры Payme и SMS, домен, аккаунты сторов,
доступ операторов. См. Часть B.

## Часть D. Почему Replit решает проблему «иногда не работает»

Сейчас при локальной разработке телефон ходит в API по Wi-Fi к компьютеру
(`192.168.100.180`) — связь моргает, и запросы (маршрут, карта) периодически
срываются. **На Replit этой проблемы нет:** приложение обращается к стабильному
публичному `https`-адресу, а не к домашней сети. То есть развёртывание на Replit
и есть настоящее решение перебоев, которые видны в дев-режиме.
