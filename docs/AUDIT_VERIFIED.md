## 🔴 Безопасность / деньги (CRITICAL — чинить первым)

### SEC-01 ✅ Пароль админа сравнивается в открытом виде
- **Где:** `artifacts/api-server/src/routes/admin.ts:100` — `admin.password_hash !== password`;
  плюс мастер-вход `admin.ts:89` — `password === masterPass`.
- **Суть:** ввод сравнивается напрямую со значением в БД, без `bcrypt`/`argon2`.
  Колонка называется `password_hash`, но сравнение как с плейнтекстом.
- **Риск:** утечка БД = утечка паролей; либо (если там хеш) вход вообще не работает.
- **Фикс:** хранить `argon2`/`bcrypt`-хеш, сверять через `verify()`/`compare()`.

### SEC-02 ✅ Завершение сессии не списывает деньги с кошелька
- **Где:** `artifacts/api-server/src/routes/sessions.ts:189-213` (`PATCH /sessions/:id/stop`).
- **Суть:** стоимость считается и пишется в `cost`, но `walletsTable`/`captureHold`
  не вызываются (в файле нет ни одного обращения к кошельку). Зарядка «бесплатная».
- **Фикс:** при stop — списание/захват холда из кошелька в одной транзакции.

### SEC-03 ✅ Повторный stop накручивает стоимость (нет проверки active)
- **Где:** `sessions.ts:189-213`. Нет `if (existing.status !== 'active') return`.
- **Суть:** энергия = `powerKw * (now - started_at)`. Повторный вызов stop через часы/сутки
  пересчитывает от `started_at` → стоимость раздувается многократно.
- **Фикс:** гвард `if (status !== 'active')` в начале; считать от `ended_at`, не от `now`.

### DB-01 ✅ Деньги и координаты в `real` (float) — потеря точности
- **Где:** `lib/db/src/schema/stations.ts:16-17` (`lat/lng real`), `:21-22`
  (`power_kw`, `price_per_kwh` real); `lib/db/src/schema/sessions.ts:12` (`cost real`).
- **Суть:** `real` = Float32 (~7 знаков). Для денег — ошибки округления в биллинге;
  для координат — дрейф маркера ~1–4 м.
- **Фикс:** деньги → `bigint` тийины (`cost_tiyin`), как в `wallet.ts`; координаты →
  `doublePrecision`. Требует миграции + правок в `admin.ts` (агрегаты `sum(cost)`),
  `sessions.ts`, `openapi.yaml` + регенерация клиента.

### CON-01 ✅ Гонка (TOCTOU) при бронировании коннектора
- **Где:** `artifacts/api-server/src/routes/connectors.ts:45-64` — `SELECT` → проверка
  `status !== 'free'` (58) → `UPDATE` без `WHERE status='free'`.
- **Суть:** два параллельных запроса проходят проверку и перезаписывают бронь.
- **Фикс:** атомарный `UPDATE ... WHERE id=$1 AND status='free'`, реагировать на 0 строк.

### BUG-01 ✅ Нельзя добавить авто из каталога-оверрайда (id = -1)
- **Где:** `artifacts/api-server/src/routes/user_vehicles.ts:30` —
  `vehicle_id: z.number().int().positive().optional()`.
- **Суть:** авто из оверрайда (`vehicles.ts` searchFuzzy/overrides) отдаются с `id: -1`.
  Отправка `vehicle_id: -1` → Zod `positive()` → **400**. (Работает только если клиент
  шлёт полный набор полей вместо id — иначе добавление части машин, напр. BYD, падает.)
- **Фикс:** разрешить `-1` для оверрайдов (или `.int()` без `positive`, ветвление по -1).

## 🗺️ Баг «станция не открывается / открывается с багом» (жалоба пользователя)

Подтверждено — совокупность причин, ярче всего на **вебе** и сенсорных экранах:

### MAP-01 ✅ Leaflet: `stopPropagation` не останавливает всплытие
- **Где:** `artifacts/mobile/components/MapViewWrapper.web.tsx:231` —
  `L.DomEvent.stopPropagation(e)`, где `e` — LeafletMouseEvent, а нативное событие в
  `e.originalEvent`. Клик всплывает до `map.on('click')` (`:123`).
- **Фикс:** `L.DomEvent.stopPropagation(e.originalEvent)` (или `stop(e)`).

### MAP-02 ✅ Гонка таймаута 200 мс против «тач-клика» 300 мс
- **Где:** `MapViewWrapper.web.tsx:232-233` — `markerJustClicked` сбрасывается через
  `setTimeout(…, 200)`. На тач-экранах синтетический `click` приходит ~300 мс →
  флаг уже сброшен → `onMapPress()` → карточка схлопывается.
- **Фикс:** окно ≥ 400–450 мс или метка времени последнего клика по маркеру.

### MAP-03 ✅ Жест свайпа карточки перехватывает кнопки
- **Где:** `artifacts/mobile/components/StationQuickView.tsx:211` — вся карточка в
  `GestureDetector(Pan .activeOffsetY([0,8]))`; кнопки — обычные `TouchableOpacity`
  (`react-native`, `:10`). Микродвижение пальца отменяет тап по «Маршрут»/«Зарядиться».
- **Фикс:** `TouchableOpacity` из `react-native-gesture-handler` или `Gesture.Native`,
  порог свайпа повыше.

### MAP-04 ✅ Асинхронный `projectPoint` → мигание/телепорт карточки
- **Где:** `app/(tabs)/index.tsx:674` — `await projectPoint()` ставит `markerPos`
  асинхронно, а `selectedStationId` — синхронно. Карточка рисуется на старых
  координатах 1–2 кадра.
- **Фикс:** не рендерить карточку до готовности `markerPos` для текущей станции
  (сбрасывать `markerPos` при смене id).

## 📐 Адаптивность / вид на вебе (подтверждено скринами)

### UI-01 ✅ Поле ввода телефона растягивается на всю ширину
- **Где:** `app/(auth)/phone.tsx` — у контейнера формы нет `maxWidth` (инпут `flex:1`).
  На широком экране (ПК/монитор авто) поле уезжает во всю ширину — некрасиво (скрин).
- **Фикс:** контейнер формы `maxWidth: 420, alignSelf:'center'`.

### UI-02 ✅ Карточки каруселей растягиваются на широких экранах
- **Где:** `index.tsx:714` — `CARD_W = SCREEN_WIDTH * 0.78`, без `maxWidth`.
  На 1920px карточка ~1497px.
- **Фикс:** `Math.min(SCREEN_WIDTH * 0.78, 360)`.

### UI-03 ✅ Нет `invalidateSize`/ResizeObserver на вебе
- **Где:** `MapViewWrapper.web.tsx` — при ресайзе/повороте Leaflet не пересчитывает
  размер → серые квадраты на карте.
- **Фикс:** `ResizeObserver` → `map.invalidateSize()`.

### UI-04 ⚠️ Нет раскладки под широкие экраны авто (1024×600, 1280×720)
- **Суть:** UI свёрстан под вертикальный телефон; нижняя шторка + панели съедают
  высоту на ландшафтных экранах. Это **улучшение**, не баг: для ширины ≥768px —
  Split-View (сайдбар слева + карта справа). Большая работа, отдельной задачей.
