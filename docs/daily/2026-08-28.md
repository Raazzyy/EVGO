## Что нужно сделать руками

**1. Обновить рабочую копию на Replit.** История переписана, старая ветка
разошлась с новой. В Shell:

```bash
git fetch origin
git reset --hard origin/main
```

Если на Replit остались незакоммиченные правки — сначала сохранить их
(`git stash` или копией файлов), они не переживут `reset --hard`.

**2. Проверить, что задан `ADMIN_JWT_SECRET`.** Это ломающее изменение: без
переменной сервер теперь **не запускается**. Сгенерировать:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

**3. По желанию — `CREDENTIALS_ENCRYPTION_KEY`** (той же командой). Без неё
всё работает, но сохранить учётные данные оператора в админке не получится:
вернётся 503 с понятным текстом.
