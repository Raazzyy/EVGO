## Что нужно сделать в терминале Replit

**1. Забрать изменения**

```bash
git pull
pnpm install
```

`pnpm install` обязателен — добавились `expo-notifications` и `expo-device`.

**2. Применить миграцию настроек уведомлений**

```bash
pnpm --filter @workspace/db run push
```

Если зависнет на вопросе (нужен TTY) — прервать Ctrl+C и напрямую:

```bash
psql "$DATABASE_URL" -f docs/sql/2026-08-30-notification-prefs.sql
```

**3. Проверить**

```bash
pnpm run typecheck
```

**4. Запустить**

```bash
# API — если ещё не запущен кнопкой Run
PORT=8080 pnpm --filter @workspace/api-server run dev

# Лендинг, в другом окне Shell
API_URL=http://localhost:8080 PORT=23746 BASE_PATH=/ pnpm --filter @workspace/landing run dev
```

## Что посмотреть

**Лендинг:** страницы `/privacy` и `/terms` — переключаются на три языка,
ссылки есть в подвале.

**Приложение:**
- на экране входа появилась кнопка «Посмотреть карту без входа» — карта
  открывается без регистрации
- при попытке зайти в «Сессии» или «Профиль» гостя перекинет на вход
- после входа приложение попросит разрешение на уведомления
- в настройках переключатели уведомлений теперь влияют на реальную отправку

**Push проверяются только на реальном устройстве** — на эмуляторе Expo не
выдаёт токен. Полная проверка возможна после сборки через EAS.
