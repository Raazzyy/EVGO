## Что нужно сделать в терминале Replit

```bash
git pull
pnpm install
# Миграция кошелька (при зависании drizzle-kit push):
psql "$DATABASE_URL" -f docs/sql/2026-08-31-wallet.sql
pnpm run typecheck
```

Когда будет договор с Payme — добавить в Replit Secrets:
`PAYME_MERCHANT_ID`, `PAYME_MERCHANT_KEYS` (тест+прод ключи через запятую),
`PAYME_TEST_MODE=true` на время сертификации песочницы.
Адрес вебхука для кассы: `https://<домен>/api/webhooks/payme`.
