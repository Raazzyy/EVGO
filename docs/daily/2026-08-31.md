#итог 31.08.2026

1. **Деньги в тийинах** ✅ частично — задача 30. Новый кошелёк весь на целых
   `bigint` тийинах (1 сум = 100 тийин): деньги нельзя держать в `real`, на
   балансах это копит расхождения. Существующие display-поля (`price_per_kwh`,
   `sessions.cost`, `total_spent`) осознанно НЕ трогал — их миграция ломающая
   (45+ мест), проверить без устройства нельзя, а корректность кошелька она не
   меняет: конвертация делается на границе списания. Смигрируем вместе с
   боевым запуском Payme, когда можно проверить каждый экран
2. **Таблицы** ✅ — задача 31. `wallets`, `wallet_transactions`,
   `wallet_holds`, `payment_transactions`. SQL: `docs/sql/2026-08-31-wallet.sql`
3. **Зачисление** ✅ — задача 32. Идемпотентно по платёжной транзакции:
   повторный `PerformTransaction` от Payme зачисляет ОДИН раз
4. **Списание** ✅ — задача 33. Блокировка строки `FOR UPDATE`: две
   параллельные попытки списать с одного баланса выстраиваются в очередь.
   Проверено тестом гонки — проходит ровно одно, баланс не уходит в минус
5. **Холды** ✅ — задача 34. Заморозка под сессию, `capture` по факту (не
   больше замороженного), `release` по отмене, авто-снятие по таймауту 15 мин
6. **Роуты кошелька** ✅ — задачи 35–37. `GET /wallet`, `GET
   /wallet/transactions`, `POST /wallet/topup` (создаёт транзакцию + ссылку Payme)
7. **Payme webhook** ✅ — задачи 38, 39, 45. Все методы: CheckPerform,
   Create, Perform, Cancel, Check, GetStatement, ChangePassword.
   Тайминг-безопасная Basic-авторизация, IP-allowlist под флагом,
   `raw_payload` в журнал, ответ всегда 200 JSON-RPC
8. **Тесты** ✅ — задача 44. 12 интеграционных против Postgres: двойной
   perform, отмена после проведения, гонка списаний, нехватка средств,

9. **is_promoted** ✅ — задача 60. Уже `boolean` в схеме, краш закрыт ранее

## Что нужно сделать в терминале Replit

```bash
git pull
pnpm install
# Миграция кошелька (при зависании drizzle-kit push):
psql "$DATABASE_URL" -f docs/sql/2026-08-31-wallet.sql
pnpm run typecheck
```

Когда будет договор с Payme — добавить в Replit Secrets:
`PAYME_MERCHANT_ID`, `PAYME_MERCHANT_KEYS` (тест+прод ключи через запятую),
`PAYME_TEST_MODE=true` на время сертификации песочницы.
Адрес вебхука для кассы: `https://<домен>/api/webhooks/payme`.
